# Web/Mobile Parity Matrix

| Area | Shared rule | Web presentation | Mobile presentation | Parity check |
|---|---|---|---|---|
| Today | Current/next class is primary | Two-column dashboard hero | Single-column hero above timeline | Same subject, room, time, status |
| Live Class | Timer, actions, attendance distribution | Wide dashboard with timeline side panel | Stacked hero and readable donut | Same counts and status labels |
| Attendance | Enrolled roster only; explicit save | Table/editor | Touch roster with sticky save | Same action wording and state transitions |
| Timetable | Asia/Bangkok and session status semantics | Weekly/detail views | Daily/weekly touch cards | Same times and assignment identity |
| Profile | Current teacher identity and school | Editable form/upload | Readable identity and editable supported fields | Same profile image and names |
| Feedback | Safe, actionable Thai messages | Inline/toast | Snackbar/inline | Same semantic outcome |
| Loading/empty/error | Never imply successful data | Skeleton/card state | Skeleton/card state | State labels and accessibility summary |

Pixel-level parity is not required. Semantic, color-family, typography, and hierarchy parity is required.
