# คู่มือผู้สังเกตการณ์ UAT

อย่าช่วยผู้ทดสอบทันที เว้นแต่ติดปัญหาความปลอดภัยหรือข้อมูลหาย ให้บันทึก:

- เวลาเริ่ม/จบแต่ละงาน และการหยุดเกิน 5 วินาที
- การกดผิด คำที่ไม่เข้าใจ และจุดที่ลังเล
- Web/Android รุ่นอุปกรณ์ ระบบปฏิบัติการ แอป/เบราว์เซอร์ และเครือข่าย
- classroom/session แบบ synthetic ที่ใช้
- ระดับ P0/P1/P2/P3 ตาม defect template

ห้ามบันทึกรหัสผ่าน token cookie หรือข้อมูลนักเรียนจริง
