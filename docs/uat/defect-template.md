# UAT defect template

ใช้ `uat-defects.csv` เป็นตารางกลาง โดยกรอกเฉพาะข้อมูลสังเคราะห์และข้อมูลที่ไม่ใช่ความลับ

- P0: security, data loss, cross-tenant exposure, login ไม่ได้, core workflow ใช้ไม่ได้
- P1: workflow blocked, ข้อมูล authoritative ผิด/ค้าง, ช้ารุนแรง, scope ห้อง/นักเรียนผิด
- P2: สับสนหรือช้าแต่มี workaround
- P3: visual polish หรือ enhancement
