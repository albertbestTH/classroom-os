# คู่มือทดสอบ Classroom OS (UAT)

นี่คือระบบทดสอบ ไม่ใช่ระบบจริง โปรดใช้บัญชีที่ได้รับและข้อมูลสังเคราะห์เท่านั้น ห้ามใส่ข้อมูลนักเรียนหรือข้อมูลส่วนตัวจริง

## เริ่มใช้งาน

- เปิด Web จากลิงก์ HTTPS ที่ผู้ดูแลส่งให้ หรือ install APK ภายในที่ระบุ `UAT` ในหน้าโปรไฟล์
- ใช้อีเมล/รหัสผ่านในเอกสารส่งมอบส่วนตัว ห้ามส่งต่อในแชตสาธารณะ

## งานที่ต้องลอง

1. เข้าสู่ระบบ
2. ดูคาบถัดไป
3. เริ่มคาบเรียน
4. เช็กชื่อ
5. เปลี่ยนนักเรียนสังเคราะห์หนึ่งคนเป็น “สาย” และอีกคนเป็น “ลา”
6. บันทึก
7. กลับหน้า Live Class และตรวจยอด
8. จบคาบเรียน
9. เปิดตารางของวันถัดไป
10. แก้ไขโปรไฟล์
11. ออกจากระบบ
12. ทดสอบลืมรหัสผ่านเมื่อผู้ดูแลแจ้งว่าเปิด mail-capture แล้ว

ใช้เวลาประมาณ 20–30 นาที หากพบปัญหาให้จดหน้าจอ งานที่ทำ เวลา อุปกรณ์ เครือข่าย และข้อความที่เห็น โดยไม่แนบข้อมูลจริง
